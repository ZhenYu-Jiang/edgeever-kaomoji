# 颜文字 · EdgeEver 插件

把常用的小表情放在手边：搜索、收藏、最近使用，一键插入笔记或复制到其他地方。

## 安装与更新

在 EdgeEver 插件市场填写仓库地址：

```text
https://github.com/ZhenYu-Jiang/edgeever-kaomoji
```

已经安装的用户在插件管理中检查更新至 **1.1.0**。本版新增 `storage` 能力，用于在当前设备保存收藏、最近使用和插入/复制模式，不发送网络请求。

## 使用

打开命令「颜文字」：

- **搜索**：输入“开心”“可爱”“生日”“爱心”或英文关键词；可以结合分类、收藏和最近使用筛选。
- **收藏**：点击卡片右上角的 ☆，再点 ★ 取消。收藏不会触发插入。
- **最近**：记录最近成功插入或复制的 24 个表情，重复使用会移到最前面。
- **插入**：点击表情插入当前可编辑文字笔记的光标处，可连续选用。
- **复制**：切换为复制模式后点击表情，可粘贴到聊天或其他应用；无需先打开笔记。浏览器需允许剪贴板访问。

原有 11 个分类和全部表情保留。搜索框支持 Esc 清空；所有操作可以通过 Tab、Enter/空格访问。界面跟随宿主文字颜色，适配浅色、深色和窄屏窗口。

收藏、最近使用和操作模式通过 EdgeEver 的插件存储保存在当前设备、当前工作区，不承诺跨设备同步。存储暂时不可用时会提示；插入/复制失败不会误记为成功使用。

## 开发与验证

插件无运行时依赖；`main.js` 内联样式，`styles.css` 是兼容现有分发形式的占位资产。

```sh
npm ci
npx playwright install chromium
npm test
```

浏览器测试使用隔离的 EdgeEver API 模拟环境，覆盖搜索、收藏持久化、最近使用、复制/插入失败、存储异常和窄屏。它们不读取真实笔记或登录信息，不替代实际宿主中的最终验收。

推送版本标签（如 `1.1.0`）后，GitHub Actions 先运行测试，再生成包含 `manifest.json`、`main.js` 和 `styles.css` 的 Release。标签必须与 manifest 版本一致。主分支测试通过后也会检查尚未发布的版本标签，只有分发文件与标签内容一致才补发；已存在的 Release 不会被覆盖。
